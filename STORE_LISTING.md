# Store listing — Pocket Preview

**Name:** Pocket Preview - Responsive Phone View

**Short description (132 char max):**
See any web page at real phone sizes. One click opens it in a phone-sized window: iPhone, Pixel, iPad and more.

**Category:** Developer Tools

**Detailed description:**
Pocket Preview is the fastest way to check how a web page looks on a phone.

Click the toolbar icon on any page, pick a device, and the page opens in a window sized to that device, iPhone SE, iPhone 14, iPhone Pro Max, Pixel 7, Galaxy S, or iPad mini. Flip Landscape for the rotated view.

Because it opens a real browser window (not an embedded frame), it works on every site, including ones that block being framed. No sign-in, no account, no tracking.

Great for designers, developers, and anyone who wants a quick mobile sanity check without opening DevTools.

**Features**
- One-click phone-sized preview of the current page
- Common device presets, portrait and landscape
- Works on any https page
- No data collected, no permissions beyond the active tab

**Permissions justification:**
- `activeTab`: read the URL of the page you are on when you click the icon, so it can be re-opened at a phone size. Nothing else is accessed, and no data leaves your browser.

**Privacy:** See PRIVACY.md — the extension collects, stores and transmits nothing.
